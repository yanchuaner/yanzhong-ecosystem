# 0003：燕中生态 IP、正式名称与技术命名分层

- 状态：已采纳
- 日期：2026-08-13
- 影响：公开产品名、英文名、域名、仓库、包、环境变量和观测字段

## 背景

现有界面和文档曾混用生态关键词、正式英文名、学校名称与技术标识，导致 Logo、metadata、包名、搜索结果和对外文档口径分裂。治理需要同时保留“燕中”与 `yanchuaner` 的生态 IP 属性，并给正式生态名称、产品名和技术命名划出明确边界。

## 决策

1. “燕中”与 `yanchuaner` 均为生态 IP 和核心关键词，不互为翻译，也不分别代表两套生态。
2. 生态唯一正式中文名称为“燕中生态”，英文名称为 `Yanzhong Ecosystem`。
3. 公开核心产品使用“燕中主站 / Yanzhong”、`燕中 API / Yanzhong API`、`燕中 AI / Yanzhong AI`、`燕中科创实验室 / Yanzhong Lab`。
4. `yanchuaner` 同时是稳定数字标识，用于域名、账号、仓库、包、API 路径、数据库对象、schema 与代码命名空间；`YANCHUANER_*` 保持为环境变量前缀。技术、开源和品牌来源场景可以准确使用该关键词，但不将它扩写或翻译为另一个生态名称。
5. `YCZX Code` 是已登记的独立产品名，所属关系通过产品说明和法律入口表达。
6. 学校名称的历史英文短写不作为生态品牌、产品名或界面文案。公开界面、metadata、分享图、通知、文档标题和新版权署名统一使用 `Yanzhong`。
7. 学校法定名称只在准确事实中保留，不与“生态”、API、AI、Lab 或其他产品名组合。
8. 第三方项目名、既有域名、包名和兼容协议名不因品牌统一而破坏性改写。

## 理由

- 同时登记“燕中”与 `yanchuaner`，避免品牌治理误删任一生态 IP 或把二者误解为新旧替换关系。
- `Yanzhong` 对应“燕中”，使正式中英文名称与公开产品名保持一致。
- `yanchuaner` 作为生态关键词和数字标识保留，维持域名、代码和开源组织的连续性，同时不产生第二个生态名称。
- 统一英文名减少搜索、分享、安装说明和跨产品导航中的身份分裂。

## 代价

- Lab、部分主站英文文案和 AI 界面需要渐进迁移。
- 技术命名空间、账号和域名继续使用 `yanchuaner`，品牌收敛不能演变成破坏该 IP 标识的全局重命名。
- 旧截图、缓存、发布材料和外部链接需要按发布周期清理。

## 回滚

若公开调研或权利核查证明该英文体系不可用，先停止新增资产，再以新 ADR 选择替代名称。域名、仓库和环境变量保持兼容，不通过一次性全局替换回滚。
