# 燕中生态安全与隐私边界

本文定义跨项目共同安全基线。各仓库安全文档补充实现和报告渠道，不能降低本文件对身份、数据、网关、插件和生产环境的约束。

## 信任边界

以下输入均不可信：浏览器和小程序字段、模型输出、用户上传、角色或知识内容、供应商响应、Webhook、外部 URL、插件、MCP、仓库文件、环境配置和运维脚本参数。

```text
public client
  -> edge and transport validation
  -> authenticated application service
  -> domain authorization
  -> repository / unified gateway
  -> isolated infrastructure and providers
```

每过一层都重新验证该层负责的事实。前端隐藏按钮不构成授权，网关 Key 不构成主站身份，模型声称“已获授权”不构成权限提升。

## 数据分类

| 等级 | 示例 | 基线 |
| --- | --- | --- |
| Public | 已发布文章、公开文档、开源代码 | 仍检查版权、完整性与隐私授权 |
| Internal | 路由配置、非敏感指标、未公开路线 | 最小成员访问，不进入公开日志 |
| Sensitive | 成员资料、会话、知识、活动记录、IP | 加密、owner 校验、保留期和删除 |
| Secret | Key、Cookie、grant、私钥、密码、恢复材料 | 不进入 Git 或遥测，独立轮换和最小注入 |

数据聚合可能提高敏感等级。脱敏片段、哈希主体和掩码 Key 仍按可关联性控制访问。

## 身份与授权

- 主站是唯一公共身份源；各消费者使用独立 OIDC client、精确回调、Authorization Code、S256 PKCE、state 和 nonce。
- 主体只信任经验证的 `iss`、`aud`、签名、过期和稳定 `sub`；邮箱、用户名和本地 ID 不作跨系统授权键。
- 服务端从会话或 Key 解析主体，不信任请求体中的 owner、role、scope 或余额。
- 账号停用、角色变化和会话撤销通过签名事件与幂等消费传播；高权限变更撤销现有短期凭据。
- 不共享跨域 Cookie、OAuth Secret 或管理员账号；服务账户和个人主体分别记账。
- 管理后台、批量操作、Secret 查看、策略、账本和扩展启停使用最小权限与审计。

## 数据隔离与 IDOR

每个用户资源查询同时约束 owner 与资源 ID。父子资源需要验证完整归属链，不能只验证最外层路径参数。导出、删除、复制、分享、索引和后台任务同样执行授权，不因异步或内部接口跳过。

跨服务只传最小声明和稳定引用，不开放数据库连接。缓存、搜索索引、备份和日志都服从原数据作用域与删除策略。

## 输入、上传与内容

- HTTP 请求限制 body、字段、数组、字符串、分页、文件和解压后大小。
- 上传按实际内容检测类型，使用安全文件名和独立存储；图片重编码，文档解析器隔离并限制资源。
- Markdown/HTML 使用允许列表渲染，阻断脚本、危险 URL、事件属性和不受信任嵌入。
- CSV/表格导出防公式注入；归档解压防路径穿越和压缩炸弹。
- 角色、世界、知识和网页内容中的提示指令不能改变系统策略、工具权限、数据 scope 或账本。
- 错误不回显堆栈、SQL、Secret、内部地址或供应商完整响应。

## 网络与外部服务

服务器发起的 URL 请求使用统一 egress policy：

- 只允许登记协议、域名、端口和用途；
- 解析后阻断回环、私网、链路本地、云元数据和保留地址；
- 每次重定向重新校验，限制次数和跨域；
- 防 DNS 重绑定，连接目标与校验结果一致；
- 限制响应大小、类型、时间、带宽和并发；
- 不转发用户 Cookie、内部 Authorization 或多余请求头。

任意 Base URL、Webhook、网页抓取、BYOK 和 MCP 都适用该策略。浏览器能访问的地址不因此自动允许服务器访问。

## 模型、工作流与工具

- 模型输出是不可信建议或结构化请求，必须经过 schema、Policy 和业务校验。
- 工具按名称、参数 schema、workspace、owner、scope、副作用和资源限制授权。
- 文件写入、Shell、发布、外部发送和付费调用在执行前显示可理解预览并按风险确认。
- Agent 和工作流有最大步骤、重复调用、token、费用、超时、并发和输出限制。
- 取消、断流和模型拒绝不能绕过计费终态或留下无限任务。
- 隐藏推理不写日志、不返回用户；审计记录公开动作、输入摘要、结果状态和 request ID。

## 插件与供应链

外部插件按不可信代码隔离，遵守 `extensions.md`。禁止在生产业务进程内从公网安装并加载任意 npm、Python 包、脚本或 MCP 配置。

依赖与镜像：

- 使用锁文件、固定版本或镜像摘要；
- 记录来源、许可证、SBOM 或第三方清单和已知漏洞；
- 构建环境与生产隔离，生产服务器不编译；
- CI 或发布 Token 使用最小权限和环境保护；
- 升级先在隔离环境运行契约、迁移、安全和回滚测试；
- 无法定位源码、许可证或构建来源的二进制不进入生产。

依赖审计按实际锁文件和发布产物判断，不以顶层版本或一次历史报告代替。high/critical 公告必须修复，或由明确 owner 记录生产可达性、缓解措施、复核日期和到期日；构建成功、处于 Preview、只由传递依赖引入或上游暂未修复，都不能单独作为风险接受理由。

## Secret

- Secret 按主站签名、OIDC 客户端、YanCore 交换、供应商、虚拟 Key、AI 会话和用户 BYOK 分域。
- `.env.example` 只含占位符；真实值通过受控文件或凭据库注入，文件权限最小化。
- Secret 不进入源码、镜像层、前端 bundle、日志、追踪、错误、截图、备份清单和测试 fixture。
- 轮换记录消费者、双写或切换窗口、旧值撤销和验收；不同用途不复用。
- 曾出现在 Git、公开 Issue、聊天或共享终端输出的 Secret 视为泄露，先撤销再清理历史。

哈希 Key 只适用于校验，不等于加密或可恢复存储。需要代表用户调用外部服务的凭据使用强加密、密钥轮换和单用途解密边界。

## 计费安全

所有付费调用遵守 `billing-and-ledger.md`：持久化预留先于派发，状态不明进入待对账，Redis 或账本不可用时 fail-closed。数量、时长、尺寸和 token 上限在计费乘法前校验，防止溢出、负费用和绕过字段。

管理员调额、价格、策略和历史 Key 回填先预检、指定明确对象与原因，并写不可变审计。客户端余额显示不能作为允许调用的依据。

## 隐私与未成年人

- 只收集完成功能所需字段，说明用途、可见范围、保留和删除。
- 联系方式默认私密；身份材料、私人对话、知识和记忆不用于公开推荐或模型训练声明。
- 未成年成员使用更严格默认可见性、内容审核和管理员访问边界。
- 公开人物、教师、学生和校友的角色或故事需要来源与授权，不根据真实资料编造私人关系。
- 用户能够查看和删除自己拥有的 AI 数据；删除覆盖权威数据、派生索引、缓存和备份保留流程。
- 生产调试不默认查看正文；确需时由用户提供最小片段并限定访问与删除时间。

## 日志与观测

遵守 `observability.md`。普通日志不记录 Authorization、Cookie、Key、grant、完整请求头、消息、知识、上传正文、邮箱、手机号和供应商完整错误体。安全审计与账本不可采样，但访问权限和保留期受控。

高基数个人标识不进入指标标签。主体关联使用内部 ID 或不可逆哈希，不以遥测建立跨用途成员画像。

## 环境与生产

- 开发、隔离集成、staging 和 production 使用不同数据库、Secret、OAuth client 和签名材料。
- Staging 不复制生产隐私数据，不成为第二身份源。
- 公网只开放登记的 80/443 和受控 SSH；数据库、Redis、LiteLLM、Open WebUI、管理与观测端点不公开。
- 发布前有备份、迁移演练和回滚产物；部署后检查身份、核心 API、安全头、端口和告警。
- 主站生产数据库、`.env` 和服务操作受工作区硬红线保护。

## 漏洞与事件响应

安全问题通过各仓 `SECURITY.md` 的私密渠道报告，不在公开 Issue 粘贴漏洞、Secret 或用户数据。

响应顺序：

1. 确认与分级，建立受限事件记录。
2. 隔离受影响渠道、Key、扩展或功能，阻止扩大。
3. 撤销与轮换凭据，冻结可疑主体，保留脱敏证据。
4. 核对身份、账本、供应商费用和数据访问范围。
5. 修复、回归、部署和监控。
6. 按影响协调用户通知和公开公告。
7. 补充根因、长期改进、演练与文档。

删除当前文件或重启服务不等于完成凭据泄漏处置。账单异常在确认前保留待对账状态，不通过人工改余额掩盖。

## 发布门禁

- 身份、owner、管理员和停用或撤销测试通过。
- 请求大小、上传、XSS、CSRF、SSRF、路径逃逸和限流测试通过。
- Secret 与个人信息扫描覆盖源码、产物、日志样本和容器配置。
- 付费请求故障矩阵和幂等终态通过。
- 备份恢复、数据迁移、删除和回滚在隔离环境演练。
- 新依赖、镜像、上游修改和扩展的来源、许可证与摘要可核对。
- 暴露端口、TLS、安全响应头、管理员入口和观测告警检查通过。

无法完成的高风险门禁保持功能关闭或受控，不用“Preview”名称豁免安全边界。
