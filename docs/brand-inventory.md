# 燕中生态品牌资产登记

更新时间：2026-08-13。

本文登记各产品当前可见名称、资产来源和迁移缺口。命名与使用规则见 `brand.md`，第三方权利边界见 `upstream-and-ip.md`。本表记录事实，不把“已使用燕中文案”等同于“品牌资产权属已经完备”。

## 状态口径

| 状态 | 含义 |
| --- | --- |
| 已登记 | 路径、用途、作者或来源、许可证和使用者均可追溯 |
| 待补来源 | 资产已在使用，但缺少作者、生成过程或许可记录 |
| 待设计 | 产品已有名称，尚无可复用的正式资产 |
| 待迁移 | 仍使用旧名称、临时资产或不一致 metadata |
| 法定保留 | 第三方归属或功能性商标，不属于燕中品牌替换范围 |
| 内网限定 | 只允许出现在受控管理或兼容界面，不作为公网产品身份 |

## 资产记录字段

正式资产至少登记：

- 稳定资产 ID、所属产品和用途；
- 可编辑源文件与各导出文件路径；
- 作者、权利人、许可证、外部来源和生成方式；
- 尺寸、色彩空间、透明背景、深浅主题和最小使用尺寸；
- 当前版本、首次发布、使用者和缓存失效方式；
- 替换资产、弃用日期和删除前的引用检查。

只有导出 PNG、线上 URL 或构建产物，不能视为资产源。使用生成式工具制作资产时，记录所用工具、输入来源、人工修改和权利复核结果，不把模型名称写进产品界面。

## 迁移顺序

1. 建立母品牌源文件和资产记录，确定图标、字标、单色版及最小尺寸。
2. 补主站现有图标和分享图的来源；来源无法确认时以有记录的新资产替换。
3. 为 AI、Lab 和小程序补齐 favicon、分享图、发布素材与法律入口，并统一英文产品名。
4. 为 API 建立独立燕中公网外壳或受控品牌配置；不删除 New API 的法定归属和受保护标识。
5. 将邮件、通知、CLI 包、镜像、帮助页和观测服务名纳入同一清单。
6. 发布时按实际构建产物检查旧名称、旧图标、默认链接和缓存，不只搜索源码目录。

## 完成条件

- 每个公网入口首屏、浏览器 metadata、分享卡片和错误页可以识别所属燕中产品；
- 每个资产能追溯到源文件、作者或来源、许可证、版本和使用者；
- “燕中”与 `yanchuaner` 均作为生态 IP 和核心关键词保持可识别，正式名称只使用“燕中生态 / Yanzhong Ecosystem”；
- 历史英文短写不出现在公开品牌面，“燕川”只用于法定名称和准确事实；
- 第三方归属清楚可达，但不被呈现为燕中母品牌；
- 新页面和新发布物不再引入未登记的临时 Logo、默认名称或来源不明素材。
