# 燕中生态品牌治理

本文定义燕中生态如何形成统一、可扩展、可依法交付的产品身份。第三方许可证和来源边界见 `upstream-and-ip.md`。

代码和文档的 AGPL 许可不自动授权项目标识；非官方发行版与学校/第三方标识边界见根目录 `TRADEMARKS.md`。

## 品牌层级

| 层级 | 名称 | 用途 |
| --- | --- | --- |
| 生态 IP 与核心关键词 | 燕中、`yanchuaner` | 共同构成生态识别锚点；不互为翻译，也不分别扩写生态名称 |
| 母品牌 | 燕中生态 / Yanzhong Ecosystem | 跨产品、开源组织、统一入口与公共叙事 |
| 核心平台 | 燕中主站、燕中 API、燕中 AI、燕中实验室 | 稳定服务与子域 |
| 产品 | 燕中校友汇、YCZX Code、后续 App | 面向明确用户和场景的独立入口 |
| 能力 | YanCore、统一 AI API、角色世界、知识与工作流 | 技术或产品能力，不单独冒充品牌 |

新名称应说明所属层级、目标用户、域名/包名和退场方式。不得仅为一次活动创建永久品牌或子域。

## 命名规则

- “燕中”与 `yanchuaner` 均为生态 IP 和核心关键词；前者是中文品牌与产品命名基础，后者也是稳定数字标识。
- 生态正式名称只使用“燕中生态”，英文名称只使用 `Yanzhong Ecosystem`；不得从任一关键词或学校法定名称派生第二个生态名称。
- 公开产品英文名使用 `Yanzhong`：`Yanzhong API`、`Yanzhong AI`、`Yanzhong Lab`；`YCZX Code` 保留已登记名称。
- `yanchuaner` 用于域名、账号、仓库、包、schema 命名空间和兼容环境变量，也可作为独立生态关键词准确展示；使用时保持完整拼写，不将其翻译或扩写为其他生态名称。
- 历史英文短写不再用于新增产品、资产、metadata 或版权署名。
- 学校法定名称只在准确事实中使用，不与“生态”、API、AI、Lab 或其他产品名组合。
- 域名、仓库、包、镜像、服务和观测名称保持可映射，但不要求机械相同。
- 对外模型名和能力名属于 API 契约，不使用供应商渠道 ID。
- “YanCore”专指燕中主体、授权和跨应用能力契约，不作为所有模块的通用前缀。
- 第三方项目名只出现在来源、法律、运维或兼容性说明中，不作为燕中产品标题。

## 视觉资产

各产品当前资产、来源缺口和替换顺序登记在 `brand-inventory.md`。

生态品牌资产至少包括：

- 母品牌 Logo 与单色/反白变体；
- 各核心产品图标与 favicon；
- 主色、强调色、中性色、状态色和无障碍对比规则；
- 中文与英文名称的标准排版；
- Open Graph 分享图、PWA/小程序图标、CLI 文本标识；
- 默认头像、空状态、错误状态与占位图；
- 源码、许可证和第三方声明入口。

资产应放入明确的公共源目录并记录格式、尺寸、用途、作者、许可证和生成方式。禁止把线上截图或压缩产物当作唯一源文件。

## 产品一致性

所有公开入口必须一致提供：

1. 可识别的燕中产品名称和所属生态；
2. 主站统一身份入口或明确的公开访问边界；
3. 统一的帮助、隐私、安全、开源与法律声明入口；
4. 一致的基础术语、错误语义和状态表达；
5. 适合自身场景的信息密度，不强制复刻同一页面布局。

设计系统共享语义令牌和可访问性规则，不要求主站、AI、Lab、小程序和 CLI 使用同一视觉构图。

## 品牌与法律声明

- 燕中品牌位于产品主入口；第三方归属位于清晰可访问的法律/开源页面。
- 衍生软件界面按许可证保留适当法律通知、原项目身份和修改说明。
- 不使用第三方 Logo 暗示合作、背书或自主版权。
- 替换第三方默认 Logo、名称或链接前，核对许可证附加条款与商标政策。
- AGPL 网络服务提供对应源码入口；源码链接不得隐藏在不可访问的管理员区域。

## 迁移清单

每个公开产品维护以下检查项：

| 类别 | 检查对象 |
| --- | --- |
| 浏览器 | title、description、favicon、manifest、OG 图、错误页 |
| 界面 | Logo、产品名、导航、登录、空状态、默认内容、帮助入口 |
| 通信 | 邮件、通知、分享卡片、API User-Agent、CLI banner |
| 分发 | 包名、镜像名、安装说明、截图、发布说明 |
| 法律 | LICENSE、NOTICE、第三方清单、源码、安全和隐私入口 |
| 观测 | service、component、application 等稳定名称 |

品牌迁移与功能增量同步进行。新增页面或能力不得继续引入待替换的第三方品牌资产。

## 变更流程

- 母品牌名称、Logo、核心色或产品层级变化需要生态 ADR。
- 单个产品的图标、页面视觉和文案在项目设计文档中维护，但不得改变母品牌含义。
- 新资产合入前检查移动端、深浅主题、透明背景、最小尺寸、对比度和许可证。
- 删除旧资产前搜索代码、文档、部署、metadata 和缓存引用，并保留可回滚发布物。
